**LOAN DEFAULT ANALYSIS USING SQL AND POWER BI**

**PROJECT OVERVIEW**
Analyzed 39,717 loan records from the Lending Club Dataset(2007-2011) to examine loan statuses, calculate default rates, and identify default patterns across borrower and loan characteristics.

**TOOLS USED**
- SQL: Data analysis, conditional aggregation, grouping, and default rate calculations.
- Power BI: Dashboard development and data visualization.

**KEY TASKS**
- Analyzed loan statuses to distinguish loans with known outcomes from ongoing loans.
- Calculated default rates using charged-off loans relative to loans with known outcomes.
- Compared default rates across loan grades and borrower and loan characteristics using SQL queries.
- Developed an interactive Power BI dashboard featuring summary cards and visualizations to present key metrics and lending trends.

**KEY FINDINGS**
The analysis examines default rates across loan grades and borrower and loan characteristics to identify patterns in loan repayment outcomes.
